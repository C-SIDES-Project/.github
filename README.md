# C-SIDES Project

This is the shared information hub for the **C-SIDES Project** GitHub organization.

Use this page to find the right project, get help, and coordinate work. Installation instructions and analysis settings live in each project's documentation.

## Projects

| Repository | What it does | Where to start |
| --- | --- | --- |
| [CoastSatCLI](https://github.com/C-SIDES-Project/CoastSatCLI) | Runs CoastSat shoreline extraction and analysis using Landsat and Sentinel imagery, with a graphical interface and a command-line pipeline. | [Setup and recommended GUI workflow](https://github.com/C-SIDES-Project/CoastSatCLI#setup), then the [documentation hub](https://github.com/C-SIDES-Project/CoastSatCLI/blob/main/docs/README.md). |
| [PlanetScopeCoastSat](https://github.com/C-SIDES-Project/PlanetScopeCoastSat) | Extracts shorelines and transect time series from four-band PlanetScope imagery, with image alignment and optional tidal correction. | [Installation and analysis guide](https://github.com/C-SIDES-Project/PlanetScopeCoastSat#installation), then the [example notebook](https://github.com/C-SIDES-Project/PlanetScopeCoastSat/blob/main/example.ipynb). |
| [.github](https://github.com/C-SIDES-Project/.github) | Holds this organization overview, support information, and the team's workflow guides and issue forms. | This README and the guides linked below. |

For a first analysis, choose the repository that matches your imagery and follow its setup guide. Review the site inputs, processing settings, and extracted shorelines before using the results in an analysis. Each project's documentation covers its workflow, limitations, and acknowledgements.

## Working together

- **Report a problem, suggest a change, or ask a project question:** open an issue in the relevant repository. An issue is a shared record of a question or task.
- **Track planned and active work:** use the existing [CoastSatCLI Kanban board](https://github.com/orgs/C-SIDES-Project/projects/1/views/1).
- **Make a small code or documentation change:** follow the [short guide for team changes](docs/contributing.md).

Follow the [issue and board workflow](docs/issues.md) to record a task, keep its progress visible, and close it when finished. Reporting an issue or joining a discussion can be done entirely on GitHub, without installing Git or changing code.
