# Questions and support

Questions about the organization, project setup, or an analysis workflow can be directed to **Phillip Steeves** at [phillip.steeves@nrcan-rncan.gc.ca](mailto:phillip.steeves@nrcan-rncan.gc.ca) or [@phillipjws on GitHub](https://github.com/phillipjws).

For questions or problems useful to the team, open an issue in the relevant repository:

- [CoastSatCLI issues](https://github.com/C-SIDES-Project/CoastSatCLI/issues) for its setup, GUI, pipeline, and analysis outputs.
- [PlanetScopeCoastSat issues](https://github.com/C-SIDES-Project/PlanetScopeCoastSat/issues) for PlanetScope imagery preparation, shoreline extraction, and transect analysis.
- [Organization hub issues](https://github.com/C-SIDES-Project/.github/issues) for shared guidance, project links, and organization-wide coordination.

Describe what you are trying to do and where you need help. For a failed run, include the step, error message, and relevant settings if available. You do not need to identify the cause before asking. Mention `@phillipjws` if you need his input.

See the [issue and board workflow](https://github.com/C-SIDES-Project/.github/blob/main/docs/issues.md) for how to open and track an issue. Use email for material that cannot be shared in the repository; leave API keys, credentials, and restricted data out of issue text and attachments.
