# C-SIDES Project

We use satellite imagery to map shorelines and analyse coastal change.

## Find a project

| Project | Purpose |
| --- | --- |
| [CoastSatCLI](https://github.com/C-SIDES-Project/CoastSatCLI) | CoastSat processing of Landsat and Sentinel imagery through a GUI or command-line pipeline. |
| [PlanetScopeCoastSat](https://github.com/C-SIDES-Project/PlanetScopeCoastSat) | Shoreline extraction and transect analysis using four-band PlanetScope imagery. |

Start with the selected project's README for installation and analysis instructions.

## Coordinate work and get help

Our team uses GitHub issues to record problems, ideas, questions, and analysis tasks, and the existing [CoastSatCLI Kanban board](https://github.com/orgs/C-SIDES-Project/projects/1/views/1) to track work.

- [Organization information hub](https://github.com/C-SIDES-Project/.github#readme)
- [Issue and board workflow](https://github.com/C-SIDES-Project/.github/blob/main/docs/issues.md)
